# Security Policy

## Supported versions

Only the latest published version of `@iqdoq/dom-to-image` receives security fixes. Versions follow
[semantic versioning](https://semver.org/); a fix is released as a new patch version.

## Reporting a vulnerability

Please do **not** open a public issue for a security vulnerability.

Report it privately through GitHub instead: on the
[Security tab](https://github.com/iqdoq/dom-to-image/security) choose **Report a vulnerability**
([private vulnerability reporting](https://docs.github.com/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)).

Please include the affected version, a description of the issue and, if possible, a minimal example that
reproduces it. We will acknowledge the report and keep you informed about the fix.

The original [tsayen/dom-to-image](https://github.com/tsayen/dom-to-image) is no longer maintained; vulnerabilities
in code inherited from it are handled here as well.
